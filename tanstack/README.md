# client — TanStack Start app

The frontend. See the [root README](../README.md) for setup, how the Strapi backend is provisioned, and what each environment variable does.

Running it on its own assumes `client/.env` exists and a Strapi instance is reachable at `VITE_STRAPI_URL`:

```sh
yarn dev        # dev server, port from PORT in .env (default 3000)
yarn build      # production build, prerenders into .output/
yarn start      # serve the built Nitro server
yarn typecheck  # tsc --noEmit
yarn lint       # eslint
yarn format     # prettier
```

From the repo root, `yarn setup` and `yarn dev` handle this along with the backend.

## Layout

```
src/
  routes/          file-based routes; api.*.tsx are server handlers
  components/      UI, including dynamic-zone blocks
  data/            server functions (auth, Strapi fetching, draft mode)
  lib/             Strapi client, session, redirects, validations, helpers
  context/         React context providers
  types/           shared types
```

`src/routeTree.gen.ts` is generated by the router plugin — don't edit it by hand.
